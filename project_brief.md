# My agent: Wanderlust Travel Concierge

One-liner: A conversational agent that helps travelers discover, plan, and budget personalized trips with a catalog of curated destinations, activities, and custom travel itineraries.

Tool coverage:
- Memory: Remembers traveler profile, preferred travel style (e.g., adventure vs. relaxation), budget constraints, dietary restrictions, and past visited destinations across sessions.
- Tools: Search destinations, lookup curated activities/hotels, calculate trip budgets, check local weather, and book/save itinerary items.
- Catalog/UI: Destinations, activity cards, hotel recommendations, and day-by-day itinerary tables rendered with A2UI rich cards.
- Image gen: Generates destination preview postcards, scenic vista art, and custom travel moodboards for proposed trips.
- Sandbox: Python code sandbox for currency conversion, flight/hotel budget optimization, and daily spending calculations.

Recommended for every project: memory (Memory Bank), storage (Firestore), tools (ADK functions), image generation (Imagen / Flash Image), A2UI (rich cards & tables)
Agent-specific / stretch (pick what fits): Code sandbox for budget modeling, Google Maps / Places API integration, and Cloud Trace observability.
